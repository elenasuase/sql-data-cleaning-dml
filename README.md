# 🧹 SQL: Limpieza de datos y DML (Transformación con UPDATE, DELETE y tipos de datos)

Este repositorio contiene una píldora formativa sobre el uso de SQL para la limpieza y transformación de datos, centrándose en sentencias DML como `UPDATE` y `DELETE`, así como en la correcta gestión de tipos de datos.

## 🎯 Objetivos

- Comprender la importancia de la limpieza de datos
- Aplicar transformaciones usando SQL
- Utilizar correctamente `UPDATE` y `DELETE`
- Identificar y manejar distintos tipos de datos

## 📚 Contenido

### 📊 Presentación
Presentación teórica creada en Canva:
- Conceptos de limpieza de datos
- Tipos de datos en SQL
- Uso de `UPDATE`
- Uso de `DELETE`
- Buenas prácticas
